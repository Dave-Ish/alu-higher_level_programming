Python - Classes and Objects

This directory contains solutions for the Python - Classes and Objects project in the ALU Higher Level Programming curriculum. It covers core Object-Oriented Programming (OOP) concepts in Python, including classes, objects, private instance attributes, properties, getters, setters, and instance methods.

Requirements

• Interpreted on Ubuntu 20.04 LTS using Python 3.8.5
• Compliant with pycodestyle (version 2.7.*)
• All files are executable and include Google-style docstrings for modules, classes, and methods

Files

• 0-square.py: Defines an empty class Square.
• 1-square.py: Defines a Square class with a private instance attribute size.
• 2-square.py: Validates that size is an integer greater than or equal to 0.
• 3-square.py: Adds the public instance method area to compute the square area.
• 4-square.py: Adds property getter and setter methods for size.
• 5-square.py: Adds the public instance method my_print to display the square with # characters.
• 6-square.py: Adds the private instance attribute position with validation and coordinate offset printing.
